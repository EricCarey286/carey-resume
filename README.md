- [Next.js](https://nextjs.org/) - A React framework that simplifies server-side rendering and optimizes performance

## Getting Started

To suggest updates programmatically, follow these steps:

1. Clone the repository to your local machine:
```git clone https://github.com/ericcarey286/carey-resume.git```
2. Navigate to the project directory:
```cd carey-resume```
3. Install the dependencies:
```npm install```
4. Start the development server:
```npm run dev```
5. Open your web browser and navigate to [http://localhost:3000](http://localhost:3000) to view the project.

You will need a YoutubeAPIv3 API key stored in a .env file
